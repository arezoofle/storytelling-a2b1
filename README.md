# Storytelling en français — A2–B1

Une mini-application autonome pour huit séances d'expression orale et de storytelling. Elle fonctionne sans installation : ouvrez `index.html` dans un navigateur.

## Publier avec GitHub Pages

1. Connectez-vous à [GitHub](https://github.com) puis cliquez sur **New repository**.
2. Nommez le dépôt `storytelling-a2b1`, choisissez **Public**, puis cliquez sur **Create repository**.
3. Dans le dépôt, cliquez sur **Add file** → **Upload files** et déposez le contenu de ce dossier : `index.html`, `style.css`, `app.js` et `README.md`. Cliquez sur **Commit changes**.
4. Ouvrez **Settings** → **Pages**. Dans **Build and deployment**, sélectionnez **Deploy from a branch**, puis la branche **main** et le dossier **/(root)**. Enregistrez.
5. Après une ou deux minutes, GitHub affichera l'adresse publique du site. Copiez-la pour vos apprenants.

Pour changer les consignes ou les cartes, modifiez les listes dans `app.js`, puis enregistrez et validez la modification sur GitHub.
